🐍 Інтерактивний урок: Перевірка умов у Python

1. Теоретична довідка

У Python для прийняття рішень використовуються умовні оператори. Вони дозволяють виконувати певні блоки коду лише тоді, коли виконується (є істинною) якась умова.

  • if (якщо) — перша головна перевірка.
  • elif (інакше якщо) — додаткові перевірки, якщо попередні умови не виконалися. Може бути декілька.
  • else (інакше) — виконується, якщо жодна з попередніх умов не виявилася правильною.

2. Приклад коду на Python

Розглянемо класичну програму для визначення типу температури води:

if t >= 100:
    print("Вода кипить (Пар)")
elif t > 0:
    print("Вода в рідкому стані")
else:
    print("Вода замерзла (Лід)")
